В ходе практики в колледже УКБУиТК по специальности Информационные Системы и Программирование (2 курс) мной была разработана Код для управления магазином и складом.
Моя краткая структура проекта:
База данных (DBConnector): Связь с MySQL, реализация поиска и обновления данных.
Архитектура: Использование шаблона MVC (Model-View-Controller).
Клиентский блок (HelloApplication, HelloController): Витрина товаров, поиск, формирование корзины и оформление покупки с автоматическим пересчетом суммы.
Административный блок (StaffHelloApplication, StaffController): Инструментарий для персонала по приемке и списанию товаров.
Модель данных (Product): Объектное описание сущностей магазина.
Механизмы запуска (Launcher, StaffLauncher): Раздельные точки входа для разных ролей пользователей.(Админ и Покупатель)
Так же была добавлена корзина для товара так как это онлайн магазин.
Результат: Готовое приложение с CRUD-операциями (создание, чтение, обновление), работающее с реальной СУБД и имеющее графический интерфейс на JavaFX.
Для использования вам остается лишь сделать SQL файл и дописать в сам код где находится ваш файл.
